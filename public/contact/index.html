Contact

Prime Suspects is made and maintained by one person, so everything lands in the same inbox and a human reads it.

Email

barnir@agentmail.to — the only contact channel. There is no support form, no ticket queue, and no phone number.

Reporting a bug

The most useful bug report says which browser and device you were on, what the lineup looked like, which probes you had played, and what you expected to happen instead. Because the game keeps no server-side record of your session, a case cannot be reconstructed from this end — your description is the whole evidence file. If a probe stamped out a suspect it should not have, say which probe and which number, and that is usually enough to find it.

Issues and pull requests

The project is open source. Bugs, probe ideas, and balance arguments are all welcome as issues on the GitHub repository, which is often faster than email because the code is right there.

For agents and automated clients

There is no API and no MCP server; the product is the page. A plain description of the game, written for machines, lives at /llms.txt and is the right thing to read if you are summarising Prime Suspects for someone.
