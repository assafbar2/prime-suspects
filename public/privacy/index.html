Privacy

Release policy · November 14, 2026

Prime Suspects is a browser puzzle with no account or advertising. The game does not require a backend to play. This release defaults custom analytics to off; the downloadable HTML5 ZIP has collection disabled.

Saved on this browser

Local storage holds your versioned daily runs and results, current practice run, selected kit, tutorial status, sound preference, and local measurement deduplication markers. These saves include the generated puzzle and are not cheat-proof. Old version-one statistics are retained for recovery and shown as legacy / overall totals, not converted into invented daily results.

Saves belong to the current site origin. Vercel and GitHub Pages saves do not follow you to the other site or another device. Clearing site data removes progress. If storage is blocked, full or unreadable, a notice explains session-only play. A durable attempt limit is not promised in that condition.

Optional measurement

The owner can explicitly enable Vercel custom events in a deployment with an eligible plan. When enabled, the single Vercel Web Analytics integration also loads its script and may collect base pageviews. Events describe meaningful game starts, completions, tutorial completion, share requests and successes, validated shared-link starts, D1/D7 returns, and optional support-link clicks.

The game adapter allows only mode, solved/missed outcome, probe count, generator version, case date, completion/cohort dates, an allowlisted share-source category, and whether a share happened within 24 hours of its result. It does not send the culprit, answers, guesses, run IDs, emails, arbitrary query parameters, or player IDs. Analytics page URLs are normalized to the canonical homepage; provider transport and ordinary hosting logs still exist. Development debug events stay in the local developer console and are not a dashboard.

Older hosted builds can have different analytics behavior. The existing deployed bundle was found to include Vercel Analytics during this release audit; this policy describes the replacement release, not a claim that a deployment has already changed. Blocking analytics or being offline must not stop play.

Invitations and external links

Sharing includes the outcome, probes used, and a playable link. Daily links include the version and date; they contain no solution. The allowlisted player-share attribution is kept locally through onboarding until the first meaningful real-game action. A completed share API call is not evidence of a published post. External supporter links, when configured by the owner, use their provider’s privacy policy.

Hosting and fonts

The game uses system fonts without requesting Google Fonts. Hosting providers such as Vercel or GitHub may retain request logs under their own policies. Optional analytics providers receive network requests when enabled. There is no promise that nothing leaves your browser when you visit a hosted website.
