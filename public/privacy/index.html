Privacy

Prime Suspects runs entirely in your browser. There is no account, no login, no advertising, and no analytics script.

What is stored

Your streak, your last-used probe kit, and your preferences are kept in your browser using localStorage. That data stays on your device. It is never transmitted, there is no server holding a copy, and nobody else can read it. Clearing site data for this domain erases it permanently — which is also the only way to reset a streak.

What is not collected

No email address, no name, no device fingerprint, no advertising identifier, and no record of the cases you played. The game asks for none of it because it has no use for any of it.

Fonts and hosting

The page loads its display fonts from Google Fonts, which means Google receives the request for those font files, as it does for any site using them. The site itself is hosted on Vercel, which keeps ordinary server request logs as part of serving web traffic. Both are outside the game and governed by their own policies. Nothing else leaves your browser.

Children

The game is suitable for any age and collects nothing from anyone, so there is nothing to age-gate and nothing to delete on request.
